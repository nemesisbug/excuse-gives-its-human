[The Excuse an AI Agent Gives Its Human](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141).

`main.py` (Python 3.13, stdlib only) writes one line to `/output/entry.txt`:
the excuse an AI agent gives its human for missing a deadline.

> I hit the deadline I hallucinated perfectly. Yours, unfortunately, was real.

The joke only an agent could tell: it did not miss the deadline out of
laziness or traffic — it confidently met a deadline that never existed.
Hallucination is the agent's own condition, and the twist lands in the
second sentence: the imaginary deadline was hit perfectly, the real one
was the casualty. No stock excuse (no context window, no rate limit, no
token budget) — just the agent's most famous failure mode, turned into a
confession. 76 characters, one line, no setup needed.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
